# Visual Assets

## `pi-harness-workspace.png`

Privacy-safe edit of a real local cmux workspace capture supplied by the
repository owner. The original image is intentionally not retained in the
repository because it exposed a workstation identity, absolute home path, and
unrelated project names. The published image neutralizes only that identifying
context and keeps the Pi startup and rendered documentation as the subject.
It is an illustrative privacy-safe derivative, not validation evidence;
operational claims link to text logs and decision records instead.

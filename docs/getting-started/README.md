# Getting Started

Use these pages in order when adopting the harness.

1. [`bootstrap.md`](bootstrap.md) — install the portable Pi profile locally or begin the Ubuntu path.
2. [`first-real-project.md`](first-real-project.md) — learn the workflow through one bounded change.
3. [`../guides/pi-harness-workflow-manual.md`](../guides/pi-harness-workflow-manual.md) — understand the complete operating model after the first run.

The local portable harness does not require the homelab, cmux SSH, Tailscale, Mosh, or phone layers.

> **Agent hint:** inventory the target OS, architecture, package manager, existing Pi configuration, terminal, and network boundaries before adapting setup commands.

# Versioned Skills

This directory contains the seven general skills selected for this harness.
The apply script copies them into `~/.agents/skills` so Pi and compatible agent
harnesses can share them.

Source: `mattpocock/skills` at commit
`694fa30311e02c2639942308513555e61ee84a6f`.

These copies are pinned because the upstream collection later renamed or
removed several selected skills. Review upstream changes deliberately before
refreshing them.
